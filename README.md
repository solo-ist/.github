# .github

Org-level GitHub configuration for [solo.ist](https://solo.ist).

- `profile/README.md` — rendered as the org landing page at
  [github.com/solo-ist](https://github.com/solo-ist). Its copy is derived from
  `COPY-landing.md` in the `solo-ist` site repo; keep the two in step.
- `profile/assets/` — images referenced by that page, by absolute
  `raw.githubusercontent.com` URL (relative paths are unreliable on org profiles).
